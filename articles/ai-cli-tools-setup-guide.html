AI 命令行工具安装指南：Claude Code / Codex / Gemini CLI 上手教程 2026

一、三大 AI CLI 工具速览

2026 年，AI 编程助手已经不再是 IDE 插件的天下——命令行里的 AI Agent 正在成为开发者的主力工具。它们不像传统插件那样只能补全代码，而是可以直接在终端里读取项目、修改文件、执行命令，像一个真正的"同事"一样和你协作。

目前市面上一共有三款主流选择：

工具 开发商 核心定位 适用场景
Claude Code Anthropic 终端 AI Agent 大型项目重构、架构级任务、多文件协同修改
Codex CLI OpenAI 终端 AI 编码助手 快速原型、脚本编写、轻量级代码任务
Gemini CLI Google 终端 AI 助手 多模态任务（图像理解）、Google 生态集成

三款工具各有千秋，后面的章节会逐一讲解安装步骤，最后附上对比帮你做选择。

二、安装前的准备工作

在开始安装之前，请确认你的系统满足以下基础条件：

  • Node.js 18+ — Claude Code 和 Gemini CLI 都基于 Node.js 运行。在终端输入 node -v 查看版本，如果没有安装，去 nodejs.org 下载 LTS 版本
  • Python 3.8+ — Codex CLI 依赖 Python 环境。输入 python --version 确认
  • 稳定的网络连接 — 三款工具都需要联网使用，部分下载可能需要科学上网
  • 终端基础 — 知道如何打开终端（Windows 用 PowerShell 或 CMD，Mac/Linux 用 Terminal）
小提示：Windows 用户如果遇到兼容性问题，可以考虑安装 WSL2（Windows Subsystem for Linux），它会提供一个完整的 Linux 环境，三款工具在 WSL2 中运行都非常顺畅。

三、Claude Code 安装

Claude Code 是 Anthropic 推出的终端 AI Agent，特点是能理解大型项目的完整上下文，擅长架构级的代码修改。当前支持 Windows、macOS 和 Linux。

3.1 Windows 安装

方式一：npm 全局安装（推荐）

PowerShell / CMD
npm install -g @anthropic-ai/claude-code

安装完成后，在终端输入 claude 即可启动交互会话。

方式二：如果 npm 不可用，可以用 WSL2

WSL2 (Ubuntu)
# 先在 WSL2 中安装 Node.js curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash - sudo apt-get install -y nodejs # 再全局安装 Claude Code npm install -g @anthropic-ai/claude-code

3.2 macOS 安装

Terminal
# 推荐：Homebrew 安装（一条命令搞定） brew install claude-code # 或者用 npm 全局安装 npm install -g @anthropic-ai/claude-code

3.3 Linux 安装

Terminal
# 确保 Node.js >= 18 node -v # npm 全局安装 npm install -g @anthropic-ai/claude-code # 验证安装 claude --version

3.4 启动和使用

安装完成后，在项目目录下运行：

任意终端
claude # 进入交互界面后直接输入任务描述 # 比如："帮我在 src/ 下新建一个 utils.ts"
实用技巧：在 VS Code 或 Cursor 中打开项目后，按 Ctrl+` 调出内置终端，直接在里面跑 Claude Code，相当于把 AI Agent 嵌入了你的编辑器。

四、OpenAI Codex CLI 安装

Codex CLI 是 OpenAI 推出的命令行编码助手，基于 GPT-5 系列模型，特别适合快速原型开发和脚本编写。它的优势在于响应速度快、对 OpenAI 生态的原生支持。

4.1 Windows 安装

方式一：npm 全局安装（推荐）

PowerShell / CMD
npm install -g @openai/codex

方式二：WSL2 方案（如果原生安装后 codex -V 无输出）

WSL2 (Ubuntu)
# 在 WSL2 中安装 Node.js curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash - sudo apt-get install -y nodejs # 安装 Codex CLI npm install -g @openai/codex # 验证 codex -V

4.2 macOS / Linux 安装

Terminal
# npm 全局安装 npm install -g @openai/codex # 验证安装 codex -V

4.3 启动和使用

任意终端
# 进入项目目录 cd my-project # 启动 Codex codex # 在交互模式中直接描述你的需求
实用技巧：Codex CLI 支持用 codex "一句话任务" 的方式直接执行单次命令，不需要进入交互模式，适合脚本化场景。

五、Google Gemini CLI 安装

Gemini CLI 是 Google 推出的命令行 AI 工具，核心优势是支持图像等多模态输入，并深度集成了 Google Cloud 生态。如果你已经在用 Google Cloud 或需要分析截图/设计稿，它是三款中最合适的选择。

5.1 Windows 安装

PowerShell / CMD
npm install -g @google/gemini-cli

同样支持 WSL2 方案，如果原生安装遇到问题可以参考 Claude Code 章节的 WSL2 步骤。

5.2 macOS / Linux 安装

Terminal
# npm 全局安装 npm install -g @google/gemini-cli # 验证安装 gemini --version

5.3 启动和使用

任意终端
gemini # Gemini CLI 支持粘贴图片路径进行多模态分析 # 比如："分析这个截图中的 UI 布局问题 ./screenshot.png"
实用技巧：Gemini CLI 的多模态能力是它独有的卖点。你可以直接给它截图，让它帮你分析错误信息、审查 UI 布局，甚至从设计稿生成前端代码。

六、三款工具对比：该选哪一个？

对比维度 Claude Code Codex CLI Gemini CLI
安装难度 简单（npm 一行搞定） 简单 简单
大型项目 ⭐⭐⭐ 最强 ⭐⭐ 中等 ⭐⭐ 中等
代码重构 ⭐⭐⭐ 优势领域 ⭐⭐ 还行 ⭐⭐ 还行
快速脚本 ⭐⭐ 还行 ⭐⭐⭐ 优势领域 ⭐⭐ 还行
多模态（图像） 不支持 不支持 ⭐⭐⭐ 独有优势
Google 生态 不相关 不相关 ⭐⭐⭐ 原生集成
社区活跃度 高（增长最快） 高 中等（较新）

选择建议：

  • 做大型项目重构、多文件修改 → Claude Code
  • 写脚本、做快速原型、习惯 OpenAI 生态 → Codex CLI
  • 需要图像分析、用 Google Cloud → Gemini CLI
  • 不确定选哪个？先从 Claude Code 开始，它的综合体验在 2026 年评价最高
不用纠结：三款工具可以同时安装，它们互不冲突。你可以根据具体的任务类型灵活切换，就像工具箱里同时有扳手和螺丝刀一样。

七、常见问题与排障

7.1 安装后命令不识别

现象：终端提示 command not found: claude 或类似错误。

解决：

  • 检查 npm 全局安装路径是否在系统的 PATH 环境变量中
  • 运行 npm list -g --depth=0 确认包已安装
  • Windows 用户尝试关闭并重新打开终端
  • macOS/Linux 用户运行 source ~/.bashrc 或 source ~/.zshrc 刷新环境变量

7.2 Windows 原生安装后无反应

现象：在 PowerShell 中运行命令后没有任何输出，也不报错。

解决：

  • 先确认 Node.js 版本是否 >= 18：node -v
  • 尝试用管理员权限运行终端
  • 如果仍然不行，建议切换到 WSL2 方案——目前 WSL2 是三款工具在 Windows 上最稳定的运行环境

7.3 macOS 提示"无法验证开发者"

现象：macOS Gatekeeper 弹窗提示无法打开。

解决：使用 npm 安装方式不受 Gatekeeper 影响。如果你下载了独立安装包，在终端运行 chmod +x 文件名 赋予执行权限后再试。

7.4 网络相关错误（401 / 403 / 404 / 超时）

错误码 含义 排查方向
401 / 403 认证失败 检查 API Key 是否正确、是否已激活、是否有对应工具的访问权限
402 / 429 额度耗尽或限流 检查使用额度是否用完，等待额度重置或升级套餐
404 请求地址错误 检查 API 端点地址配置是否正确
长时间无响应 网络不稳定 检查代理设置，稍后重试或切换网络环境
注意：如果你使用的是第三方 API 代理服务，请确认 Key 对应的产品线是否正确——Codex、Claude Code 和 Gemini CLI 的 Key 通常是不通用的。

7.5 如何彻底卸载？

三款工具的卸载方式相同，因为它们都通过 npm 安装：

任意终端
# 卸载 Claude Code npm uninstall -g @anthropic-ai/claude-code # 卸载 Codex CLI npm uninstall -g @openai/codex # 卸载 Gemini CLI npm uninstall -g @google/gemini-cli

如果还需要清除残留的配置文件和缓存，可以检查以下目录：

  • Windows: %USERPROFILE%\.claude\、%USERPROFILE%\.codex\、%USERPROFILE%\.gemini-cli\
  • macOS/Linux: ~/.claude/、~/.codex/、~/.gemini-cli/

结语

2026 年的 AI CLI 工具已经非常成熟。从安装到使用，门槛比一年前低了很多——基本都是一条 npm 命令搞定。三款工具的核心差异不在安装上，而在于你用它们来做什么：重构找 Claude Code，脚本找 Codex，图像找 Gemini。

如果你是刚接触 AI 编程的新手，建议从 Claude Code 开始。它的交互体验最友好，对中文支持也最好，能帮你从第一个终端命令开始，逐步建立起用 AI 写代码的习惯。
