研究生论文AI工作流

一套覆盖选题、文献综述、实证分析、论文润色全流程的AI工具方案。不堆工具列表，每一步告诉你用哪个、怎么用、避什么坑。

适用：研一论文、MBA论文、本科毕业论文 · 预计阅读 5 分钟

Step 01

选题定位：从模糊方向到可执行的研究问题

🔎 Perplexity 📋 Notion

导师给了方向但没说具体做什么？先用 Perplexity 搜"你的领域 + research gap 2024-2026"，它会自动引用文献来源。把有趣的题目扔到 Notion 里建一个"选题池"表格，列三列：题目/可行性/数据来源。一周后回来删掉80%，剩下的就是值得做的。

💡 关键原则：选题之所以难，不是因为没想法，而是因为想法太多。Perplexity帮你快速判断哪些想法已经被人做过了。
Step 02

文献综述：从100篇到20篇核心文献，再写到5000字综述

🤖 Elicit 🌙 Kimi ✅ Grammarly

不要在 Google Scholar 上逐篇下载。用 Elicit（elicit.com）输入研究问题，它会自动给你一张表格：每篇文献的方法、样本量、主要发现——一目了然。筛选出20篇核心文献后，把PDF全部拖给 Kimi（支持200万字上下文），让它提炼"三派争论"和"研究空白"。动手写综述时，每写完一段用 Grammarly 检查学术英语表达。

💡 Elicit 的"提取研究特征"功能是文献综述的神器——你再也不需要一篇篇打开PDF看方法论了。
Step 03

数据处理与实证分析：让AI帮你写代码、跑回归、debug

⌨️ Claude Code 💬 Claude 🐙 GitHub Copilot

这是大多数文科研究生的噩梦——但AI恰好最擅长写代码。把你的数据和要跑的分析告诉 Claude（比如"我有面板数据，想做固定效应回归和稳健性检验"），它会给你完整的 Python/Stata 代码。复杂分析用 Claude Code 直接在项目文件夹里批量操作；日常写代码用 GitHub Copilot 在 VS Code 里实时补全。遇到报错直接把错误信息丢给Claude——它平均30秒定位bug。

💡 不要自己从零写代码。告诉AI"我想要什么结果"比告诉它"怎么写"更高效。你提供经济学逻辑，它提供代码实现。
Step 04

写作润色与降重：从初稿到终稿的最后一步

💬 Claude 🔄 QuillBot ✅ Grammarly

把实证结果和讨论大纲喂给 Claude，让它生成初稿框架——AI不会替代你的学术判断，但它能帮你把碎片思路组织成流畅段落。写完初稿后，用 QuillBot 的改写模式逐段降重（修改措辞但不改变学术含义），再用 Grammarly 做最后一遍语法检查。三段式处理法：Claude启框架 → QuillBot降重 → Grammarly收尾。

💡 降重的核心不是"换词"，而是"改写句子结构"。QuillBot的"学术模式"专门干这个。
Step 05

格式规范与参考文献：没人想手动调格式

📚 Zotero 📊 Gamma

用 Zotero（免费）管理所有参考文献，安装浏览器插件后一键保存文献信息，Word里装Zotero插件就能自动生成参考文献列表——格式自动匹配APA/Chicago/GB/T 7714。答辩PPT用 Gamma 生成初版，告诉它你的论文主题和章节结构，20秒出一个设计精美的初稿。

💡 现在就装Zotero浏览器插件。等你论文写完再手动整理参考文献，至少要花一个下午。

⭐ 一个研究生的避坑清单

  • 不要用ChatGPT直接写论文正文——它编造的引用看起来很真但根本不存在
  • 实证代码让AI写但必须自己理解——答辩时老师会问"为什么用这个模型"
  • Perplexity搜到的文献必须去CrossRef验证——AI搜索引擎的引用偶尔不准确
  • 每周备份一次Notion和Zotero——数据丢了AI救不了你
  • Grammarly免费版就够用——研究生不需要付费版也能写出合格的英文论文
